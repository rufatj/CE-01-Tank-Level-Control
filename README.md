# CE-01: Tank Level Control

## Overview

This project simulates the water level inside a tank using a simple dynamic model implemented in Python.

The objective is to understand the fundamentals of process dynamics before implementing advanced control strategies such as PID control.

## Features

- Tank level simulation
- User-defined tank parameters
- Water level visualization
- Python implementation

## Technologies

- Python
- NumPy
- Matplotlib
- SciPy

## Future Improvements

- Dynamic outlet flow
- PID controller
- Transfer function
- Realistic process model
